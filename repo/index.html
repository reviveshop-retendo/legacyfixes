YouTube works. The YouTube package pulls in a vendored, source-built TubeReplacer backend (GPL-3.0), which restores search, playback and sign-in for the classic App Store YouTube app (1.0–2.0) on iOS 5–10. The other fixes use per-app version/API rewrites; TextNow Legacy is a separate standalone client rather than a tweak. See the cards below.

Packages

LegacyFixes All-in-One

com.legacyfixes.allinone

1.2.0

Metapackage that installs every app fix below in one tap. Remove it later if you only want some of them.

LegacyFix: YouTube

com.legacyfixes.youtube

1.1.0

Working fix. Restores the classic App Store YouTube app (versions 1.0–2.0) by installing the vendored, source-built TubeReplacer backend.

  • Search, home feed, playback and sign-in work again
  • Automatic dependency: dev.preloading.tubereplacer 2.0.2
  • Update-nag suppression and the configurable hook engine also included
Configuration

TubeReplacer settings appear in Settings → TubeReplacer after installing.
LegacyFixes overrides: /var/mobile/Library/Preferences/com.legacyfixes.com.google.ios.youtube.plist

Restart the app after changes. Logs go to /var/mobile/Library/Logs/LegacyFixes/.

LegacyFix: YouTube Kids

com.legacyfixes.youtubekids

1.1.0

Google never shipped a backend replacement for the old YouTube Kids client, so this package hands the app over to the YouTube Kids web client in an in-app browser.

  • Keeps the app icon and gives access to the kid-safe catalogue
  • Configurable URL and delay; set WebFallback=false to keep the native UI
  • Update-nag suppression and the shared engine included
Configuration

Defaults: /Library/Application Support/LegacyFixes/Patches/com.google.ios.youtubekids.plist
Per-device overrides: /var/mobile/Library/Preferences/com.legacyfixes.com.google.ios.youtubekids.plist

iOS 6/7 may need a TLS 1.2 backport for the web fallback to load.

LegacyFix: Facebook

com.legacyfixes.facebook

1.1.0

Fix for Facebook 11.x on iOS 6–8. Repairs the system Facebook-account integration and makes the app report a supported version.

  • Rewrites the three broken system-integration calls (privacy_options, me/links, auth.login)
  • Spoofs FBAppVersion / FBPlatformVersion in-process — no app-bundle edits
  • Hides forced-update alerts
Notes

Use Facebook 11.0 (the last iOS 6 build) and enable 2FA on your account before logging in. If login stops at “Confirm Identity”, approve it from a newer device; see the bag-xml guide.

Logs: /var/mobile/Library/Logs/LegacyFixes/

LegacyFix: Messenger

com.legacyfixes.messenger

1.1.0

Makes old Messenger builds report a currently accepted client version, which gets past the “wrong credentials”/forced-update wall.

  • Spoofs FBAppVersion 447.0.0.43.106 / FBPlatformVersion 447.0.0
  • Update-nag suppression
  • Per-device overrides if a different build needs other numbers

Messenger is server-strict and end-to-end encryption changes may still block some accounts; this removes the client-side gate.

TextNow Legacy

com.legacyfixes.textnow

1.0.0

Standalone app, not a tweak. An unofficial native TextNow client for iOS 7+ (armv7), written for the iPhone 4. It talks to TextNow's web API directly because the current App Store app needs iOS 15 and TextNow's web client requires modern JavaScript.

  • Sign in with your own TextNow account; session cookies are kept in the Keychain
  • Conversation list with unread badges, compose, chat history and SMS sending
  • Lightweight polling (no WebSocket) so it runs on old Foundation/WebKit
  • Installs /Applications/TextNowLegacy.app; independent of the official app

Requires iOS 7.0+, so it is not included in the iOS 6-capable All-in-One package. The password is only saved if you enable “Remember password”. Accounts that use Google/Apple sign-in must set a TextNow password first.

Notes

This is an unofficial client — TextNow may change or block its web API at any time, and it is not affiliated with TextNow. Use it only with your own account. Install it from this source, then launch TextNow Legacy from the Home Screen.

No TextNow credentials are bundled with the package.

Install

Jailbreak first (e.g. with Legacy iOS Kit), then:

  1. Open Cydia / Sileo / Zebra → Sources → Edit → Add.
  2. Paste the source URL above.
  3. Install LegacyFixes All-in-One, or pick individual packages.
  4. Respring and launch the app. Check logs if something misbehaves.

On iOS 6, Cydia's APT may not negotiate TLS 1.2 with GitHub Pages. If the source refuses to load, install a TLS backport such as TLSFix first, or use an HTTP mirror.

Fixes are built for iphoneos-arm (32-bit) with a deployment target of iOS 6.0; TextNow Legacy targets iOS 7.0. Only install on devices you own. No DRM or paid-feature bypasses are included.

Source code and build instructions live in the GitHub repository.
