Heads up: the generic layer (update-nag suppression, OS/User-Agent spoofing, config-driven hooks) is useful on its own, but resurrecting a dead service API needs per-app reverse engineering. Packages

LegacyFixes All-in-One

com.legacyfixes.allinone

1.0.0

Metapackage that installs every app fix below in one tap. Remove it later if you only want some of them.

LegacyFix: YouTube

com.legacyfixes.youtube

1.0.0

Compatibility layer for the App Store YouTube app and its older releases.

  • Hides “update required / no longer supported” alerts
  • Optional iOS version and User-Agent spoofing
  • Config-driven hook engine + class/method dumper for writing real API fixes
Configuration

Defaults: /Library/Application Support/LegacyFixes/Patches/com.google.ios.youtube.plist
Per-device overrides: /var/mobile/Library/Preferences/com.legacyfixes.com.google.ios.youtube.plist

Restart the app after changes. Logs go to /var/mobile/Library/Logs/LegacyFixes/.

LegacyFix: YouTube Kids

com.legacyfixes.youtubekids

1.0.0

The same compatibility layer for YouTube Kids (bundle com.google.ios.youtubekids).

LegacyFix: Facebook

com.legacyfixes.facebook

1.0.0

Compatibility layer for the classic Facebook app on 32-bit iOS.

Install

Jailbreak first (e.g. with Legacy iOS Kit), then:

  1. Open Cydia / Sileo / Zebra → Sources → Edit → Add.
  2. Paste the source URL above.
  3. Install LegacyFixes All-in-One, or pick individual packages.
  4. Respring and launch the app. Check logs if something misbehaves.

On iOS 6, Cydia's APT may not negotiate TLS 1.2 with GitHub Pages. If the source refuses to load, install a TLS backport such as TLSFix first, or use an HTTP mirror.

Packages are built for iphoneos-arm (32-bit) with a deployment target of iOS 6.0. Only install on devices you own. No DRM or paid-feature bypasses are included.

Source code and build instructions live in the GitHub repository.
